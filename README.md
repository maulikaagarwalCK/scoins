# Scoins nudges · concept prototype

A clickable concept prototype for my Scoins UX case study. It shows how the SalarySe home could make Scoins visible, with nudges that change with the balance:

- **new user, 0 Scoins:** learn how to earn the first ones
- **1–4 Scoins, under ₹1:** a close goal and bigger ways to earn
- **5–249 Scoins:** see Scoins as money and where to spend them
- **250+ Scoins:** an honest choice between deals and bank transfer

It is not the real SalarySe app, and nothing in it moves money.
